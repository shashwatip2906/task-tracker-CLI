# 📋 Task Tracker CLI

A task tracking cli application written in Python that is used to track tasks in a day

This is a CLI app which has no dependencies. This is an example of implementing fundamental software engineering concepts such as cli arguments parsing, file system reading/writing, JSON data format, and error handling.

## ✅ Features

- Create, update and delete tasks with ease since each task has a unique id

- Update progress of tasks to todo, in-progress or done

- List all todo items or list specific tasks based on their progress

- The application stores the data in a file called tasks.json in the local machine

- The application handles errors properly and provides feedback to the user on what went wrong

- It is easy to use and has a number of in-built features

## 🛠 Technologies Used

- Python 3 (uses inbuilt modules such as sys, os, json, datetime)

## 💻 How to Use

To get started with the application, you need to have python installed in your system

Next, you can download the repo or directly download the task_cli.py file into your working directory

Then, run the following commands:

```bash

git clone [https://github.com/your-username/task-tracker-cli.git](https://github.com/your-username/task-tracker-cli.git)

cd task-tracker-cli

```
